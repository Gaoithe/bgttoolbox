Engine Hints

This solver uses a bitmask logic engine ported directly from PocketC (0x1FF mask). Each cell stores candidates as bits (Bit 0 = 1, Bit 8 = 9).

Algorithm W (Naked Single)

Scans every empty cell on the board. If the calculated bitmask for a cell has exactly one bit left (meaning all other 8 numbers are blocked by its row, column, or 3x3 block), it places that number immediately.

Algorithm Y (Hidden Single)

Scans the 27 groups (9 rows, 9 cols, 9 blocks). For each group, it counts how many empty cells can accept a specific number (1-9). If a number can only fit into exactly one cell within that group, it is placed, even if that cell could technically accept other numbers.
